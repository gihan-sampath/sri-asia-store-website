# Sri Asia Store Website

Bilingual German and English landing page for Sri Asia, an Asian grocery store in Erlangen.

## Local development

1. Run `npm install`.
2. Run `npm run dev`.
3. Open `http://localhost:3000`.

## Deployment

The project uses Next.js and supports direct Vercel deployment. No environment variables are required.
